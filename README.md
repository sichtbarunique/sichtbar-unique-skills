# Sichtbar Unique Skills

Hier teile ich Skills für Claude, die ich selbst jeden Tag benutze. Ich bin Kerstin Schumacher von Sichtbar Unique und arbeite ohne Programmierkenntnisse nur mit Claude Code.

## Verifikation

Kennst du das? Claude sagt „fertig“, du öffnest die Seite und der Knopf geht nicht. Oder am Handy rutscht alles aus dem Bild.

Mit diesem Skill prüft Claude seine Arbeit selbst, so wie eine echte Besucherin: Seite öffnen, durchklicken, Screenshots am Computer und in Handy-Breite. Erst wenn die Screenshots zeigen, dass es läuft, gilt die Aufgabe als erledigt. Du musst dafür keine Zeile Code lesen.

### So installierst du ihn

1. Lade den Ordner `verifikation` herunter (grüner Knopf „Code“, dann „Download ZIP“, entpacken).
2. Leg den Ordner `verifikation` in deinen Skill-Ordner:
   - für alle Projekte: `~/.claude/skills/verifikation/`
   - nur für ein Projekt: `<dein Projekt>/.claude/skills/verifikation/`
3. Starte Claude Code neu. Ab jetzt greift der Skill nach jeder Änderung an einer Seite oder App. Du kannst ihn auch direkt rufen: „Prüf das mit dem Verifikations-Skill.“

Claude braucht dafür Zugriff auf einen Browser, zum Beispiel den eingebauten Browser in der Claude-App oder Claude in Chrome.
